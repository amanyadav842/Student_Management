Student Management API

Features
- User registration
- JWT login
- Student CRUD
- PostgreSQL
- Authorization
- Pagination

Tech Stack
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic

How to Run

1. Clone repository
2. Create virtual environment
3. Install requirements
4. Configure .env
5. Start server

API
POST /users/register
POST /users/login
GET /users/me
POST /students
GET /students
PUT /students/{id}
DELETE /students/{id}
